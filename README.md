# 黑神话游戏手柄录制器

这是一个用于录制和回放黑神话游戏手柄操作的Python工具。通过录制手柄操作过程，来实现自动执行操作游戏，实现刷灵蕴打怪刷内丹

## 功能特性

- 🎮 实时录制手柄操作（轴、按钮、帽子开关）
- 🔄 **循环播放**：自动重复播放录制的操作序列
- 📁 文件管理：自动保存录制文件到recordings文件夹
- ⌨️ 全局热键支持：无需切换窗口即可操作
- 🖥️ 紧凑型界面：300x300像素，右下角定位
- 📊 实时状态显示：手柄连接状态、操作日志
- 🎯 美观的GUI界面：支持中文显示，2x2按钮布局
- 🔧 手柄配置：支持自定义按键映射
- 🖱️ 键盘鼠标模拟：将手柄操作转换为键盘鼠标输入
- 📈 实时数据显示：显示当前手柄的所有输入状态

## 安装依赖

```bash
pip install -r requirements.txt
```

## 快速开始

### 1. 安装和启动
1. 确保已安装Python 3.7或更高版本
2. **快速启动**：双击 `run.bat` 文件即可启动程序（推荐）
3. **手动启动**：
   ```bash
   pip install -r requirements.txt
   python main.py
   ```

### 2. 连接手柄
1. 将北通BTP-A2P3A手柄连接到电脑
2. 确保手柄被系统识别（可以在设备管理器中查看）
3. 程序会自动检测并显示手柄状态

### 3. 基本操作
- **Shift+F9**：开始录制手柄操作
- **Shift+F10**：循环播放最近一次录制的操作
- **Shift+F11**：显示所有录制文件列表，选择播放
- **Shift+F12**：停止当前操作

## 详细使用说明

### 录制功能
1. **开始录制**：按 **Shift+F9** 或点击"录制"按钮
2. **录制过程**：
   - 程序会实时显示手柄的所有输入状态
   - 在"手柄实时数据"区域可以看到当前的手柄操作
   - 在"操作日志"区域可以看到录制状态
3. **停止录制**：按 **Shift+F12** 或点击"停止"按钮
4. **保存文件**：录制完成后自动保存到recordings文件夹

### 播放功能
1. **循环播放最近录制**：按 **Shift+F10** 或点击"循环播放"按钮
2. **选择播放**：按 **Shift+F11** 或点击"选择播放"按钮
   - 在弹出的列表中选择要播放的文件
   - 使用上下键选择，回车确认
3. **播放过程**：
   - 程序会将录制的手柄操作转换为键盘鼠标输入
   - 实际控制游戏中的角色
   - 可以在"操作日志"中看到播放状态

### 实时数据显示
程序界面包含以下实时信息：
- **手柄状态**：显示连接的手柄数量和状态
- **手柄实时数据**：显示当前手柄的所有输入
  - 摇杆/轴：显示摇杆位置和触发器状态
  - 按钮：显示按下的按钮
  - 方向键：显示帽子开关状态
- **操作日志**：显示程序的操作记录

## 手柄映射说明

### 北通BTP-A2P3A默认映射
- **左摇杆**：WASD移动控制
- **右摇杆**：鼠标视角控制
- **A按钮**：A键
- **B按钮**：B键
- **X按钮**：X键
- **Y按钮**：Y键
- **左肩键(LB)**：鼠标左键
- **右肩键(RB)**：鼠标右键
- **返回键(BACK)**：ESC键
- **开始键(START)**：空格键
- **左触发器**：Q键
- **右触发器**：E键
- **方向键**：WASD方向控制

### 自定义映射
可以编辑 `controller_config.json` 文件来自定义按键映射：
```json
{
  "button_mapping": {
    "0": {"name": "A", "key": "A", "description": "确认/跳跃"},
    "1": {"name": "B", "key": "B", "description": "取消/闪避"}
  }
}
```

## 高级功能

### 多手柄支持
程序支持同时连接多个手柄：
- 每个手柄的数据会分别显示
- 录制时会记录所有手柄的操作
- 播放时会同时控制所有手柄

### 录制文件编辑
录制文件是JSON格式，可以手动编辑：
- 修改时间戳来调整操作时机
- 删除不需要的操作数据
- 复制粘贴操作序列

### 性能优化
- 程序使用多线程处理，不影响GUI响应
- 录制数据实时保存，避免数据丢失
- 播放时精确的时间控制

## 技术特点

- **多线程处理**：录制和播放在独立线程中运行，不影响GUI响应
- **实时数据采集**：60FPS的手柄数据采样率
- **全局热键**：使用pynput库实现全局键盘监听
- **手柄支持**：使用pygame库支持多种手柄设备
- **文件格式**：JSON格式存储，便于查看和编辑

## 故障排除

### 手柄未检测到
1. 检查手柄连接
2. 确认手柄驱动已安装
3. 重启程序
4. 检查设备管理器中的手柄状态

### 热键不响应
1. 以管理员身份运行程序
2. 检查是否有其他程序占用热键
3. 确保程序窗口处于活动状态

### 播放时游戏无响应
1. 确保游戏窗口处于活动状态
2. 检查游戏是否支持键盘鼠标输入
3. 调整手柄映射配置
4. 检查游戏的反作弊系统

### 录制文件损坏
1. 检查磁盘空间
2. 确保程序正常退出
3. 删除损坏的文件重新录制

## 注意事项

1. **管理员权限**：全局热键需要管理员权限
2. **游戏兼容性**：某些游戏可能有反作弊保护
3. **手柄驱动**：确保使用最新的手柄驱动
4. **系统资源**：长时间录制可能产生大文件
5. **备份重要**：定期备份重要的录制文件
6. 确保手柄已正确连接并被系统识别
7. 录制文件可能较大，注意磁盘空间
8. 播放时请确保游戏窗口处于活动状态
